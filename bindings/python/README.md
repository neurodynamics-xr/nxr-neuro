# nxr-neuro (Python)

The Python face of nxr-neuro: pure functions over NumPy arrays (`nxr_neuro.compute`) and the readers of the field's file formats (`nxr_neuro.io`),
as one compiled module over the same C++ library as the `nxr-neuro` command. Install a wheel and `import nxr_neuro as nn`.
See `docs/reference.md`, section "The Python face", in the repository.
