# Archive: the old compute library's design documents

Historical. These documents describe the library before the refactor (stateful MEX handles, `ManifoldSurfaceMesh` facets, `createContext`, three.js and WebAssembly worker integration) and the code they describe has been removed or renamed. They are kept for the record of why things were designed as they were; for the current code read [compute/README.md](../../../compute/README.md), [../../reference.md](../../reference.md) and [../../../ARCHITECTURE.md](../../../ARCHITECTURE.md).
